# CK-Engine

[![Licence](https://img.shields.io/github/license/signature-opensource/CK-Engine.svg)](LICENSE)

The CKomposable engine: from the configuration of an application and the types of its packages to the generated code.
Its configuration and its type cache are in [CK-ResourceSpace](https://github.com/signature-opensource/CK-ResourceSpace)
(CK.Engine.Configuration, CK.Engine.TypeCollector).

| Package | Description | Latest stable |
|---------|-------------|---------------|
| [CK.Engine.TypeSet](CK.Engine.TypeSet/README.md) | The types of the BinPaths: their groups and their named type sets. | [![nuget](https://img.shields.io/nuget/v/CK.Engine.TypeSet.svg?label=CK.Engine.TypeSet)](https://www.nuget.org/packages/CK.Engine.TypeSet/) |
